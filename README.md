
# AWS Secure Cloud Environment

A hands-on project for the *Cloud Computing Fundamentals* course (CSNW3204), where I deployed and configured a secure AWS environment from scratch.

## What I Built
- **VPC Configuration** — a custom Virtual Private Cloud with subnets, route tables, and an Internet Gateway to isolate and control network traffic.
- **EC2 Deployment** — an EC2 instance launched inside the VPC, secured with a dedicated security group.
- **EBS Management** — a persistent EBS storage volume provisioned and attached to the instance.
- **IAM Policy / Security Groups** — IAM roles and policies applied following the principle of least privilege.
- **Verification** — confirmed the environment worked end-to-end.
